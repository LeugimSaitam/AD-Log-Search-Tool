# AD Log Search Tool

Python application developed to simplify the search and analysis of Active Directory log files.

## Features

- Search by username or computer name
- Fast file-based lookup
- Fallback log scanning
- Multi-threaded searches
- Export results to CSV
- Timestamp parsing and sorting
- Graphical user interface built with Tkinter
- Responsive search cancellation
- Log filtering and result limiting

## Technologies

- Python
- Tkinter
- Threading
- Regular Expressions (Regex)
- CSV Export
- Windows Administration

## Purpose

This tool was designed to help IT support teams quickly identify user logon and logoff activity by analyzing central log repositories and presenting the information in a user-friendly interface.
